# Select colors from MOSuite's default palette

Select colors from MOSuite's default palette

## Usage

``` r
select_mosuite_colors(n, ...)
```

## Arguments

- n:

  number of colors to select.

- ...:

  additional arguments (ignored).

## Value

vector of colors in hex format.

## Examples

``` r
select_mosuite_colors(5)
#> [1] "#5954d6" "#e1562c" "#b80058" "#00c6f8" "#d163e6"
```
